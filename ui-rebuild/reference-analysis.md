- Palette/material: dark burgundy glass; amber structural lines; alert red for severe; acid green for confirmed actionable states; ivory primary text.
- Type: 10–11px metadata, 20–26px numeric focus, 12px human explanation and comment.
- Cards: left severity rail, short category, readable value, scoped rank, one short comment. No decorative circular progress indicator.
- Layout target: 220–280px desktop; one column below 760px.
- Ranking language: `全国省会样本 第 03/34`; never a bare national rank.
- Emergency rule: warnings and recovery/strong-rain evidence rank first and use restrained comments.
