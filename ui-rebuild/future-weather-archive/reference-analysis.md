# Reference analysis

The 434×1316 reference is dominated by equal-weight cyan outlines, tiny utility labels, square media buttons, a table-like source ledger, and unused lower space. Its main warning has no visual authority despite being the page's decision focus.

## Replacement hierarchy

1. Bureau plaque: fictional institution, vault identity, real snapshot time.
2. Storm specimen: full-width generated weather art, official level seal, case number, real title/location/fact/boundary, themed reel controls.
3. Case rack: three layered official-warning tabs with level, title, location, and issue time.
4. Verification gate: highest official warning and deterministic city-event entry.
5. Evidence ribbon: five freshness states expressed by glyph, text, timestamp, and physical voucher treatment.

## Visual grammar

- Materials: black ceramic cabinet, smoke-purple resin, archival paper, oxidized brass, vermilion seal.
- Type: Song-style face only for institutional labels and seals; heavy Chinese sans for warning titles; narrow tabular utility face for IDs and timestamps.
- Color: official alert colors remain semantic accents; the cabinet itself uses violet, paper, and brass rather than cyan neon.
- Signature: a meteorological image preserved as a translucent physical specimen sliding out of Vault 07.
- Motion: one slow resin drift plus the existing 2.5-second case load indicator; all disabled for reduced motion.

## First-screen acceptance

- At 1366×768 and 1920×1080, current level/title/location/time are readable without scrolling.
- At least 40% of the first 600px is authored image/material rather than lines and text.
- No default browser buttons or database-like checkbox rows.
- Long warning titles wrap without horizontal overflow.
- `/live` continues to render the compact `NationalSituationHud`.
