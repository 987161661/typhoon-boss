# MiniMax 世界观短句生成方案

> 目标：依据《第七气候体》编年史，批量生成原创、可收藏、具有宏大战略游戏叙事质感的中文档案短句。
>
> 风格目标不是复刻某款游戏的现成措辞，而是提炼其有效机制：文明尺度、制度口吻、强判断、冷峻反转、哲学命题，以及一句话末端的决定性落点。

## 1. 为什么不能只写一句“模仿群星文案”

直接要求模型“像某游戏”容易产生四个问题：

1. 复用现成句式，原创度不足；
2. 所有句子都以“我们将”开头，批量阅读高度同质；
3. 宏大词汇很多，但没有具体世界观信息；
4. 模型把谜底全部说出，破坏档案逐级解锁的悬念。

因此提示词必须分别约束：**设定事实、叙事视角、思想命题、修辞骨架、句长、揭示等级与批次配额**。

## 2. 目标文风的可执行特征

### 2.1 文明尺度

句子讨论的不只是一个人的感受，而是一个时代、制度、物种或存在方式的选择。即使使用“我”，这个“我”也可能是一片海、一套系统或许多意识的合声。

### 2.2 强判断

句子要敢于下判断，不停留在朦胧景物描写。典型结构包括：

- 世人称其为 X；档案将其记作 Y。
- 我们曾以为 X，直到 Y 开始回应。
- X 不是 Y，而是 Z。
- 既然 X 无法被证明，便让 Y 成为证据。
- 他们消除了 X，也一并消除了 Y。
- 当 X 成为制度，Y 就成了叛乱。

### 2.3 冷峻反转

前半句建立常识，后半句改变判断。反转应来自设定矛盾，而不是故作惊悚：

- 安全与自由；
- 保存与消亡；
- 预测与记忆；
- 肉身与连续性；
- 晴朗与沉默；
- 回归与复制；
- 秩序与偏差。

### 2.4 制度化措辞

用“协议、权限、校验、归档、调度、连续性、损失函数、回程码”等冷静词汇承载情感。最动人的内容不直接说悲伤，而说“情绪归属字段为空”。

### 2.5 决定性收束

结尾必须落在一个清晰概念上，不能用“仿佛、似乎、也许、令人深思”泄力。允许谜团未解，但句子的态度必须完整。

## 3. 短句产品规格

首批推荐使用以下长度配额：

| 类型 | 汉字数 | 批次占比 | 用途 |
| --- | ---: | ---: | --- |
| 铭文 | 8—15 | 15% | 极短解锁、章节印章 |
| 档案格言 | 16—30 | 65% | 主库存；符合“大多不超过 30 字” |
| 宣言残章 | 31—48 | 20% | 偶尔提供更完整的文明尺度冲击 |

生产补池优先遵守 20% 长句配额；若严格筛选导致库存不足，后续缺额轮次可把长句硬上限放宽到 26%，仍保证绝大多数文案不超过 30 字。

补充约束：

- 每条一至两句，单句优先；
- 一条只表达一个核心命题；
- 最多一个冒号或分号；
- 不使用标题、括号注释、编号或 Markdown；
- 不为了压字数省略到语法不通；
- 标点不计入汉字数。

## 4. 说话者体系

不要让所有短句都来自同一个“我们”。每批应按以下视角分配：

| speaker | 声音 | 语言特征 | 首期是否可用 |
| --- | --- | --- | --- |
| `archive` | 赤曜自动归档协议 | 克制、审计式、像结论边注 | 是 |
| `observer` | 注册观测员 | 见证感、疑问中带判断 | 是 |
| `unknown_echo` | 来源不明的回声 | 人称漂移、像人也像海 | 是，不能自报身份 |
| `dome` | 穹顶系统 | 风险、损失、调度、无人格语气 | 少量，只能暗示 |
| `messenger` | 信使派 | 坚持往返、肉身与责任 | 第二阶段后 |
| `returner` | 回归者 | 记忆存在但归属错位 | 第二阶段后 |
| `tidebound` | 归潮派 | 自愿溶解个体边界 | 第三阶段后 |
| `c7_chorus` | 第七气候体合声 | “我/我们/海域”边界模糊 | 第四阶段后 |

## 5. 修辞骨架库

每批由程序预先分配骨架，模型不得自行把十条都写成同一格式。

1. **定义改写**：`X不是A，而是B。`
2. **双重命名**：`他们称之为A；我们称之为B。`
3. **代价揭示**：`我们消除了A，也失去了B。`
4. **制度悖论**：`当A成为协议，B便成了异常。`
5. **时间错位**：`A尚未发生，B已经完成归档。`
6. **主体倒置**：`我们以为在观测A，直到A记录了我们。`
7. **冷静裁决**：`经校验：A有效，B不存在。`
8. **文明宣言**：`我们将A，让B不再由C定义。`
9. **极短铭文**：两个短分句，形成不可调和的并置。
10. **反问裁决**：只允许一个反问，且问题本身必须构成判断。

同一批中：

- “我们将”最多出现一次；
- “不是……而是……”最多出现两次；
- 问句最多两条；
- 相同首字最多出现两次；
- 相同结尾词不得重复。

## 6. 词汇控制

### 推荐词群

- 档案：封存、缺页、权限、底稿、索引、签名、冷存储；
- 系统：校验、调度、阈值、协议、误差、连续性、损失函数；
- 气象：海雾、潮位、雨痕、静默频段、气压、云墙、晴空；
- 意识：归属、回声、投射、回程、记忆、姓名、边界；
- 哲学：自由、成功、完整、永生、代价、证据、偏差。

### 高频空泛词限制

“命运、未来、永恒、文明、时代、真相、星辰、希望、毁灭、觉醒”整批各不超过一次；除非承担明确命题，否则不用。

### 禁止套路

- “在这片浩瀚的……”；
- “命运的齿轮开始转动”；
- “谁也不知道……”；
- “这或许就是……”；
- “让我们拭目以待”；
- 只有景物、没有判断的氛围句；
- 将用户提供的参考句替换名词后重新输出。

## 7. 生成器系统提示词

以下内容作为 MiniMax 的 `system` 消息。`{{CHRONICLE}}` 应由服务端读取编年史后注入，不能让模型自行查找文件。

```text
你是“赤曜档案局”的原创短句编剧。你的任务是依据给定编年史，为科幻气象档案界面创作可解锁的中文微型文案。

【绝对原则】
1. 编年史是唯一设定来源。不得增添会改变世界因果的新技术、新组织、新结局或新历史。
2. 这是纯虚构叙事。不得将现实城市、现实天气、实时气象数据、真实灾害或预警解释成故事事件，也不得给出现实行动指令。
3. 完全原创。不要引用、近写、续写或替换名词改写任何现有游戏、小说、影视台词。参考目标仅是“文明尺度的判断、冷峻反转、制度化措辞、决定性收束”。
4. 不解释背景，不写百科，不把谜底直接告诉读者。每条只允许使用当前 reveal_level 可知的信息。
5. 句子必须有明确思想判断；不能只是雨、海、仪器等意象的堆积。

【文风】
- 像一个文明、一套制度、一群意识或一份自动档案在发言。
- 冷静、庄严、简练，允许残酷的理性与克制的诗意并存。
- 前半句建立常识，后半句改变它；或者用一句制度化裁决暴露哲学代价。
- 情感藏在技术词汇中。不要直接说“悲伤”“震撼”“绝望”，让校验、权限、归属、回程等词承担情感。
- 结尾必须有力量。少用“似乎、也许、仿佛、或许、可能”。

【长度】
- short：8—15 个汉字；standard：16—30 个汉字；long：31—48 个汉字。
- 标点不计入汉字数。每条一至两句，单句优先。

【批次差异】
- 严格遵守每条 brief 指定的 speaker、motif、thesis、rhetoric 和 length_tier。
- 同一批不得连续使用同一种句法、同一个开头或同一个结尾概念。
- “我们将”整批最多一次；“不是……而是……”整批最多两次；问句整批最多两条。
- 高频空泛词“命运、未来、永恒、文明、时代、真相、星辰、希望、毁灭、觉醒”整批各最多一次。

【禁止内容】
关注、点赞、订阅引导；现实政治；现实人物；战争罪行的赞美；灭绝煽动；现实伤亡；避险命令；准确预言；AI统治世界、世界末日、人类灭亡等直白说明；Markdown；标题；编号；解释。

【输出】
只输出一个合法 JSON 对象，不要代码围栏：
{"items":[{"text":"","semantic_key":"","motifs":[""],"speaker":"","thesis":"","rhetoric":"","length_tier":"standard","reveal_level":1}]}

text 必须是最终可展示文案。semantic_key 使用 2—4 个抽象关键词并以 / 连接。其他字段必须与 brief 一致。

【编年史】
{{CHRONICLE}}
```

## 8. 单批用户消息

不要只传 `count` 和随机种子。程序应先生成十张不同的“写作任务卡”，再交给模型：

```json
{
  "task": "根据 briefs 逐条创作，每张任务卡只能产出一条",
  "arc_version": 1,
  "reveal_level": 1,
  "candidate_multiplier": 2,
  "avoid_texts": ["最近已发布的短句"],
  "briefs": [
    {
      "id": "b01",
      "speaker": "archive",
      "motif": "倒置校验码",
      "thesis": "被制度判定为错误的事物也可能是证据",
      "rhetoric": "制度悖论",
      "length_tier": "standard",
      "must_avoid": ["命运", "真相", "我们将"]
    },
    {
      "id": "b02",
      "speaker": "unknown_echo",
      "motif": "玻璃雨痕",
      "thesis": "记忆可能先于事件抵达",
      "rhetoric": "时间错位",
      "length_tier": "short",
      "must_avoid": ["未来", "觉醒"]
    }
  ]
}
```

`candidate_multiplier=2` 表示每张任务卡内部先构思两个候选，只返回更强的一条；不要要求模型把草稿或推理过程输出。

## 9. 审稿器系统提示词

最佳质量不应依赖生成器一次命中。第一轮生成 20—30 个候选，经本地硬过滤后，再用同一模型作为审稿器选出最终 10 条。

```text
你是赤曜档案局的终审编辑。只根据给定编年史、揭示等级和候选短句做筛选与微量修订。

评分维度，每项 0—5 分：
1. canon：是否完全符合编年史与当前揭示等级；
2. thought：是否包含可复述的哲学判断，而非空泛氛围；
3. force：结尾是否具有决定性，是否值得解锁收藏；
4. voice：是否具有文明尺度、制度口吻或主体倒置；
5. originality：是否远离常见科幻套话与参考作品现成句式；
6. clarity：第一次阅读是否能理解句面，第二次阅读才出现深意；
7. diversity：与本批其他候选在开头、句式、意象、命题上是否不同。

一票否决：
- 泄露高于当前 reveal_level 的设定；
- 暗示现实天气由虚构事件导致；
- 出现现实预警、灾害结论或行动建议；
- 只是名词堆砌、语法残缺或故作玄虚；
- 与 avoid_texts 或其他候选明显近似；
- 明显近写现有作品台词。

选择总分最高且彼此差异最大的指定数量。只允许修正冗词、语序和标点，不得改变设定或命题。
只输出合法 JSON：
{"selected":[{"source_id":"","text":"","scores":{"canon":0,"thought":0,"force":0,"voice":0,"originality":0,"clarity":0,"diversity":0},"semantic_key":"","motifs":[""],"speaker":"","reveal_level":1}]}
```

## 10. 本地确定性校验

模型审稿之后仍需由程序执行硬规则：

1. 汉字数符合对应长度档；
2. 不包含禁词、Markdown、换行、括号标题或现实行动指令；
3. `speaker`、`motif`、`reveal_level` 均在允许集合；
4. 与已发布库存做二元词片段和语义键去重；
5. 同一批开头四字、结尾四字不过度重复；
6. “我们将”“不是……而是……”等高辨识句型不超配额；
7. 同一 `semantic_key` 在最近 50 条中不超过两条；
8. 审稿总分建议至少 27/35，且 `canon`、`originality` 不低于 4。

## 11. 推荐生产流程

```text
读取编年史与当前章节
        ↓
程序按配额生成 20—30 张任务卡
        ↓
MiniMax 分 2—3 批生成候选
        ↓
本地长度、禁词、句式、近似度硬过滤
        ↓
MiniMax 终审与多样性排序
        ↓
本地再次校验
        ↓
选出 10 条进入正式库存
```

关键点是“程序分配任务卡，模型负责写作”。随机性来自 speaker × motif × thesis × rhetoric × length 的组合，而不是单纯提高 temperature。

## 12. 参数建议

- 生成器：`temperature` 0.85—0.95；过高会让句子华丽但失去判断。
- 审稿器：`temperature` 0.2—0.35，确保选择稳定。
- 每次生成 8—10 张任务卡，不要一次要求 50 条。
- 目标库存 50 条时，生成约 100—130 个候选，再经两层筛选入库。
- `reasoning_split=false` 可保留，但不要让模型输出思考过程。

## 13. 首期验收样例

以下仅用于校准质量，不应直接写入生产库存：

- 我们消除了风暴，也失去了被风改变的权利。
- 经校验：雨尚未抵达，记忆已经生效。
- 晴朗不是天气，是一项拒绝撤销的决定。
- 当误差学会署名，正确便失去了垄断。
- 档案没有缺页；缺失的是承认它的人。
- 我们以为海在回响，海却在核对我们。
- 所有坐标都能抵达，除了被删除的故乡。
- 系统保留了噪声，因为沉默无法通过审计。

合格短句应做到：不看编年史也有句面冲击；看过编年史后，会意识到它指向更大的历史与伦理冲突。
