# Future Weather Archive assets

This folder contains the generated and optimized visual system for the root-page national right rail.

- Master visual: `storm-specimen-v1.webp`.
- Material family: twelve crops/derivatives from the same generated specimen, keeping the cabinet, plaque, controls, folders, and evidence vouchers visually coherent.
- Rebuild command:

  `node scripts/build_future_weather_archive_assets.mjs public/assets/future-weather-archive/storm-specimen-v1.webp`

- Text, warning facts, IDs, timestamps, statuses, and controls remain DOM content. These bitmaps carry only atmosphere, material, scratches, contours, and physical depth.
- The full generation prompt and source record are in `manifest.json`.
